# O Raso Também Pode Afogar

Site desenvolvido para Belly Lima como parte de um projeto acadêmico. A página apresenta o livro *O Raso Também Pode Afogar*, a coleção, informações sobre a autora e um acesso ao pré-cadastro externo.

## Tecnologias

- HTML
- CSS
- JavaScript

## Como visualizar

Abra o arquivo `index.html` em um navegador. Para que os caminhos dos arquivos e os recursos funcionem corretamente, mantenha a estrutura do projeto e a pasta `assets` no mesmo local.

## Direitos de imagem

Se quiser reaproveitar o projeto, substitua as imagens por arquivos próprios ou por imagens com licença compatível e atribuição adequada.

## Pré-cadastro

O botão de pré-cadastro direciona para um formulário externo do Google Forms. Antes de publicar o site, configure no `index.html` o endereço do formulário que será utilizado.
